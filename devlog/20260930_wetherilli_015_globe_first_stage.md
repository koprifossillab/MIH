# wetherilli 015 — 지구본 1 단계: 지금 가공물을 둥근 지구에

2026-09-30 · `feature/globe-3d` · 계획은 [wetherilli P01](20260930_wetherilli_P01_globe_3d.md)

## 1. 무엇을 했나

투영 고르기에 **지구본**을 더했다(정거원통 · 몰바이데 · 지구본). 배경(PaleoDEM 4096 폭)·기온·해안선·국경·경위선·
산지 점·분류군 점을 둥근 지구 위에 겹치고, 점을 누르면 2D 와 같은 팝업, 분류군 점에 커서를 대면 같은 말풍선이 뜬다.
시점·거르기·색·나라·분류군 찾기는 그대로 따라온다. 지형(높이)은 2 단계다.

## 2. Leaflet 층을 비춘다 — 거르기를 두 번 쓰지 않는다

처음 떠올린 길은 globe.js 가 산지 파일을 직접 읽어 점을 찍는 것이었다. 그러면 `passes`·`ageOk`·`pointColor`·같은
시대 산지·분류군 좌표 옮기기(017)를 다시 부르거나 흉내 내야 한다. 이 규칙들은 map.js 안에서 서로 얽혀 있고(환경 칸의
수·연대 범위 안내까지), 두 벌이 되면 한쪽만 고쳐지는 일이 생긴다.

그래서 **지구본은 Leaflet 층을 읽는다.** 지구본 모드에서도 Leaflet 지도는 정거원통으로 살아 있고 창(`.leaflet-map-pane`)만
숨긴다. map.js 는 지금처럼 점과 선을 Leaflet 층에 그리고, 지구본은 그 층의 표지를 하나씩 읽어 같은 모양·색·크기로
옮긴다.

- 알림은 층의 `addLayer`·`removeLayer`·`clearLayers` 를 감싸서 받는다(`watchLayer`). draw 함수마다 알림 줄을 넣으면
  이른 return 이 많아 빠뜨리기 쉽다. 점 만 개를 더해도 알림은 다음 그리기 틀(rAF)에 한 번 모인다
- 점은 Cesium 빌보드. 모양(원·세모)·채움·테두리·투명도를 캔버스 한 장으로 그려 **같은 모양은 그림을 나눠 쓴다**
  (data URL 을 열쇠로 — Cesium 의 그림 모음이 같은 열쇠를 한 번만 올린다)
- 누르기는 `scene.pick` 으로 빌보드의 `id`(= Leaflet 표지)를 얻어 표지의 `click` 을 그대로 쏜다 → `openCollection`.
  팝업만 지구본 칸으로 보낸다(`globe.popup`) — 산출 목록·기온·좌표 복사가 그대로 들어간다
- 나라로 가기(`focusCountry` 의 `fitBounds`) 같은 옮김도 Leaflet 에서 일어난다. 지구본 모드에서 Leaflet 을 손으로 움직일
  길은 없으니(손잡이를 모두 끈다) `moveend` 는 모두 코드가 옮긴 것이다 — 그 가운데·넓이로 카메라를 날린다

값: 숨은 Leaflet 도 점을 캔버스에 그린다(보이지 않는데). 만 개 남짓에서 느려지지 않았고, 규칙이 한 벌인 것이 더 크다.

## 3. 겉모습

- 점은 높이 0 에 두고 **카메라 쪽으로 60 km 당긴다**(`eyeOffset`). 겉면에 그대로 두면 지구 겉면과 깊이가 같아 반쯤
  묻히고, 깊이 검사를 끄면(`disableDepthTestDistance`) 뒤편 반구의 점이 비친다. 당기면 둘 다 피한다
- 선은 땅에서 3 km 띄운다 — 경위선의 2° 마디를 직선(현)으로 이으면 가운데가 1 km 남짓 땅속으로 꺼진다
- 배경에 음영이 구워져 있어 Cesium 의 빛(`enableLighting`)은 끈다. 대기 테두리만 둔다
- 처음 높이는 **지구가 세로 시야의 90% 를 채우는 높이**를 잰다(`sin(반각) = R / (R + 높이)`). 고정값(2.1 만 km)은 창
  모양에 따라 지구가 작게 떴다
- 팝업은 Leaflet 팝업의 칸 이름을 빌려 map.css 의 꾸밈을 받는다. Leaflet 은 지도 창 밖의 팝업을 투명하게 두어
  (`.leaflet-fade-anim .leaflet-popup`) 처음에 안 보였다 — 되살렸다. 위에 자리가 모자라면(온도계 밑) 점 아래로 펴고,
  산출 목록이 길면 지도 칸 높이로 줄여 굴린다. 떠 있는 찾기 카드(tupandactyl 002)가 밑에 있으면 그 위에서 멈춘다 — 카드가
  지도 위 가장 높은 겹(z 1100)이라 팝업을 덮었다. 누른 자리가 지구 뒤로 넘어가면 숨긴다

## 4. 도구·주소

- **전체** 는 지구 전체로 돌아간다(경도는 그대로). **링크** 는 `#age=…&proj=globe&lon=…&lat=…&alt=…`(km) 를 복사한다 —
  몰바이데의 `lon`(가운데 경선)과 이름이 같지만 뜻이 달라 `proj` 로 가른다
- **다운로드** 는 Cesium 캔버스를 그린 바로 그 틀(`postRender`)에서 옮겨 담고 2D 와 같은 띠를 붙인다. WebGL 버퍼를 늘
  남기는 `preserveDrawingBuffer` 는 켜지 않는다(GSM 048 과 같은 판단)
- **거리** 는 지구본에서 끈다 — 지구본 위에서 점을 찍고 대권을 긋는 것은 2 단계와 함께 한다
- 축척 막대·커서 기온 칸은 숨긴다. 지구본은 자리마다 축척이 달라 막대 하나로 말할 수 없다

## 5. 불러오기

Cesium.js 는 5.8 MB 라 **지구본을 처음 고를 때만** 싣는다. 싣는 동안 "지구본을 싣는 중…" 을 띄운다. 못 실으면(WebGL
없음 등) 알리고 정거원통으로 돌아간다. Cesium ion 은 부르지 않는다(`baseLayer: false`) — 사내망에서 바깥 요청이 없다.

## 6. 확인

헤드리스 크롬(SwiftShader WebGL)으로 운영 가공물을 띄워 봤다 — 250·255 Ma, 기온·국경·경위선 켜기, 점 누르기(팝업·산출
목록), *Lystrosaurus* 찾기와 말풍선, "대한민국" 으로 날아가기, 다운로드, 정거원통으로 돌아가기, 420 px 좁은 창.
`manage.py test viewer` 16 개 통과(새 문구 열쇠 포함).
