# 025 — 몰바이데에서 끌면 지구가 돈다

2026-09-30 · `feature/mollweide-rotate`

## 1. 왜

연구자: 몰바이데에서 드래그하면 지구가 회전하게 — 한눈에 보는 자리가 달라지게. 0.12.0(024)의 몰바이데는
가운데 경선이 0° 로 고정이라, 태평양을 가운데 두거나 판게아를 이음매에서 떼어 보려면 방법이 없었다.

## 2. 무엇을 했나

- **가로로 끌면 가운데 경선(lon0)을 돌리고, 세로로 끌면 지도를 옮긴다.** 적도에서 손가락 밑의 땅이 따라오게
  (Δλ = Δx · 360 / 세계 폭). 몰바이데에서는 Leaflet 의 끌기를 끄고 pointer 이벤트로 받는다. 끈 직후의 click 은
  삼킨다(점을 누른 것으로 보고 팝업을 열지 않게). 두 손가락은 Leaflet 확대에 맡긴다
- 주소에 `&lon=…` 로 남는다. 정거원통은 가운데 경선을 쓰지 않는다
- **배경을 다시 굽지 않는다.** 몰바이데 그림은 한 행이 한 위도라, 가운데 경선을 돌리는 것은 행마다 타원 안
  구간(폭 × cos θ)을 그 폭의 −lon0/360 만큼 돌려 옮기는 것과 같다. 배경을 `<img>` 대신 캔버스로 두고
  (`ReliefOverlay`) 행마다 두 조각을 그린다. 2048 폭에 2 ms, 4096 폭에 24 ms
- 기온 층도 lon0 = 0 으로 한 번 그려 두고(시점마다 캐시) 같은 식으로 돌린다
- **선은 이음매에서 끊는다**(`splitLine`) — 해안선·국경·위선. 끊는 자리는 보간해 양쪽 가장자리에 붙이고,
  자료가 ±180° 를 따라 긋는 선분(판을 자른 자국)은 버린다 — 돌리면 바다 한가운데 경선으로 보인다.
  자료는 ±180° 에서 이미 끊겨 있어(경도 도약 0) 이음매만 보면 된다
- 산지 점은 캔버스 renderer 만 다시 투영한다. 위도 → 보조각 θ(뉴턴법)는 위도마다 한 번만 푼다 — 돌려도
  위도는 그대로다

## 3. 잰 값 (헤드리스 크롬, GPU 없음)

| | 프레임 간격 중앙 / 90% |
|---|---|
| 확대 1, 산지만 | 17 / 50 ms |
| 확대 1, 국경·기온·경위선 | 17 / 67 ms |
| 확대 3(4096 배경), 국경·기온·경위선 | 17 / 50 ms |

처음엔 `map.fire("viewreset")` 로 모든 층을 다시 투영했는데, 곧 새로 그을 국경 SVG 까지 두 번 투영해
국경·기온을 켜면 90% 가 117 ms 였다. 산지 캔버스만 되돌리고 기온을 행 옮기기로 바꿔 줄였다.

## 4. 고친 것 (만들며 찾은 것)

- `lon=40` 으로 열면 지구가 옆으로 밀렸다 — 지구 전체 보기를 위경도 [0, 0] 에 맞췄기 때문. 투영 평면의 가운데는
  [0, lon0] 이다(`worldCenter`)
- 이음매에 점선 같은 틈 — 원본 구간의 양 끝(타원 가장자리)이 반쯤 투명해서. 1 px 안쪽을 읽는다

## 5. 버린 것

- **비스듬한 몰바이데**(세로로 끌면 극을 기울이기) — 배경을 행 옮기기로 돌릴 수 없고(행이 위도가 아니게 된다)
  브라우저에서 픽셀마다 다시 투영해야 한다. 세로는 옮기기로 두었다
- **lon0 마다 배경 굽기** — 360 벌을 구울 수 없다
