# tupandactyl 011 — 화면 모드: Scientific(기본)과 Casual

2026-10-01 · `feature/scientific-mode`

## 1. 무엇을 바랐나

연구자: "지금 버전을 casual 로 두고, 폰트를 사무적으로 되돌려 읽기 편하게 하고 전문용어의 영문 표기를 기본으로 하는 scientific
설정을 따로 열자". 후보(글씨체 A–D, 용어 표기 가–다, 화면 결 ㄱ–ㄷ) 가운데 **A(Pretendard)**·**나(영문만, 한글은 마우스를 올리면)**를
골랐고 화면 결은 바꾸지 않기로 했다. 그리고 "평범하게 켜면 scientific 이 먼저 뜨게".

## 2. 무엇이 바뀌나

| | Scientific(기본) | Casual |
|---|---|---|
| 본문 글씨체 | Pretendard | Spectral + 본명조 |
| 층서 단위(칩·머리말·띠·범례·최근 5 Ma) | 영문(Cenomanian) | 한글(세노마눔절) |
| 층서표 줄머리 | Era · Period · Epoch · Age | 대 · 기 · 세 · 절 |
| 퇴적 환경(나무·팝업) | 영문(PBDB 원 용어, 환경군의 영문 이름) | 한글 + 원 용어 |
| 분류 계급(찾기 후보·커서 목록·상태 줄) | 영문(family) | 한글(과) |
| 나라 이름·화면 문구 | 한국어 | 한국어 |
| 화면 결·대기 화면·제목 | 같다 | 같다 |

영문 이름에 마우스를 올리면 한글 이름이 뜬다(칩·환경 나무의 title). 영어판(`lang=en`)은 원래 모두 영문이라 모드가 글씨체만 바꾼다.

## 3. 어떻게

- 모드는 i18n.js 가 정한다 — 주소의 `mode=` → 브라우저에 기억한 것 → **scientific**. 기본이 scientific 이라 주소에는 casual 일 때만
  `&mode=casual` 이 붙는다. 바꾸면 언어처럼 다시 불러온다 — 이름을 자료 목록(index.json)을 읽을 때 바꿔 끼우므로(`localizeIndex`)
  그리는 곳마다 고치지 않아도 된다. 한글 이름은 `kn` 칸에 남겨 title 에 쓴다
- `<head>` 의 스크립트가 그리기 전에 `<html class="mode-sci">` 를 붙여 글씨체가 번쩍이지 않게. 글씨체는 `--font` 토큰 하나를 바꾼다
- Pretendard 는 한글과 라틴이 한 가족이라 한 줄에 학명·숫자·한글이 섞여도 굵기와 높이가 고르다. 가변 글꼴의 글자 묶음 92 개(3.1 MB)를
  저장소에 담았다 — 화면에 쓰인 글자가 든 묶음만 받는다
- 그림 다운로드의 밑 띠는 화면의 본문 글씨체를 그대로 읽어 쓴다
