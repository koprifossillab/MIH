# 008 — 해양기원 색을 에메랄드와 하늘색 사이(아쿠아·청록)로 옮긴다

2026-09-29 · `work/20260929-koprifossillab`

## 1. 무엇을 바랐나

007 의 에메랄드·민트를 보고 연구자가 "조금만 더 푸르게, 지금 색과 하늘색 사이로" 를 청했다.

## 2. 어떻게 정했나

눈으로 고르지 않고 **환경군마다 007 의 색과 003 의 하늘색을 HLS 로 반씩 섞었다.** 색상·채도·명도를
따로 섞으니 해안→심해로 갈수록 짙어지는 순서가 그대로 남는다. 색상(hue)은 에메랄드 156~169° 와
하늘색 204~224° 의 가운데인 **180~196°** — 옅은 아쿠아에서 짙은 청록까지다. 심해 쪽이 조금 더
푸른 것은 003 의 남색이 더 푸르렀기 때문이다.

위에서는 밝게 뜬다. 밝은 대륙붕 위의 옅은 아쿠아는 흰 테두리가 경계를 잡는다.
