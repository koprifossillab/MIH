# tupandactyl 006 — 사이트 전체를 빈티지풍으로: 가죽 머리말, 양피지, 원목, 본명조 + Spectral

2026-09-30 · `feature/vintage-theme`

## 1. 무엇을 바랐나

대기 화면(005)을 본 연구자: "사이트 전체의 디자인도 빈티지풍을 따라갔으면 한다. 가죽질, 양피지, 원목의 느낌을 참고하고,
한글·영문 글씨체도 빈티지함이 있되 학술 목적이 우선이니 가독성을 해치지 않는 후보를". 시안(아티팩트 "Wegener's Dream 빈티지
테마 시안")에서 글씨체 조합 셋과 머리말 재질 둘을 바꿔 끼워 보게 했고, 연구자는 **3안(본명조 + Spectral)** 과 **가죽 머리말**을
골랐다. 찾기 카드는 좌우를 줄여도 좋겠다고 했다.

## 2. 재질을 어디에

- **머리말 = 가죽 표지** — 짙은 갈색 그라데이션에 잡음(feTurbulence)을 얹고, 위아래에 금박 괘선 두 줄, 제목·단추는 금박색.
  책의 표지처럼 화면의 맨 위를 묶는다
- **시점 막대·패널·팝업·찾기 카드·설정 창·온도계·축척 = 양피지** — 읽고 조작하는 면. 잡음을 아주 옅게(9%) 두어 글자 뒤가
  얼룩지지 않게 했다. 패널의 절 사이는 두 줄 괘선
- **도구 묶음 = 원목에 놋쇠** — 나뭇결 줄무늬에 놋쇠색 아이콘, 눌린 단추는 놋쇠판
- **지도는 그대로** — 배경·해안선·포인트는 자료다. 색을 바꾸면 퇴적기원·시대 색의 뜻이 흐려진다. 층서 색(시점 띠·칩)만
  조금 바래게(saturate .82, sepia .1) — 색상은 그대로라 ICS 색으로 알아본다
- **어두운 판**: 연구자가 "빈티지 컨셉은 유지하되 어두운 색의 가죽질, 또는 흑단 원목 느낌으로" 를 바랐다. 양피지 자리를
  **흑단 원목**으로 바꾼다 — 같은 잡음을 가로로 길게 늘이면(baseFrequency `.004 .32`) 나뭇결이 된다. 결은 7% 로 옅게 두어 글자
  뒤가 어지럽지 않게. 머리말은 더 짙은 가죽, 금박은 조금 가라앉힌다. 토큰(`--panel`·`--parch-tex`·`--leather` …)만 바꾸므로
  모든 면이 함께 바뀐다
- **밝기 고르기**: 전에는 컴퓨터 설정(prefers-color-scheme)만 따랐다. 설정 창에 **자동 · 밝게(양피지) · 어둡게(흑단)** 를 두고
  브라우저에 기억해 `<html data-theme>` 로 입힌다. `<head>` 의 스크립트가 그리기 전에 먼저 입혀 밝은 판이 번쩍이지 않는다.
  대기 화면(고서의 종이)은 밝기와 상관없이 종이다 — 005 의 결정

## 3. 글씨체

3안의 뜻: 학술 도구라 작은 글씨가 먼저다. 빈티지 맛은 재질이 맡고 글씨는 담백하게.

- 본문 `font-family: "Spectral", "Noto Serif KR", …` — 라틴은 Spectral 이, 한글은 Spectral 에 없어 본명조가 그린다. 한 줄의
  학명(기울임)·숫자·한글이 따로 고른 글씨체로 섞인다
- 숫자는 `lining-nums tabular-nums` — 표처럼 줄을 맞춘다
- 제목(Wegener's Dream)은 La Belle Aurore 그대로(005). 대기 화면의 머리글·도판 설명도 Spectral 로 맞췄다
- 지도 칸(Leaflet)은 기본이 Helvetica 라 온도계·축척·팝업이 따로 놀았다 — `.leaflet-container` 에도 본문 글씨체
- 그림 다운로드의 밑 띠도 같은 글씨체

**담는 법**: 한글 글씨체는 크다. Google Fonts 가 글자 묶음별로 잘게 나눈 woff2 를 그대로 받아 저장소에 담고(`design/fetch_fonts.py`),
주소만 바꾼 `fonts.css` 를 쓴다. 브라우저는 화면에 쓰인 글자가 든 묶음만 받는다. 본명조는 400·600 두 굵기에 한글·한자 묶음만
(라틴은 Spectral 이 맡는다) — 모두 13 MB 로 저장소가 그만큼 커지지만 Cesium(14 MB)과 같은 결정이다: 사내망에서 CDN 이 막혀도
화면이 같아야 한다. 700 굵기는 담지 않았다 — 600 으로 충분하고 굵기마다 6 MB 씩 는다.

## 4. 버린 것

- **원목 머리말** — 시안에서 비교했고 연구자가 가죽을 골랐다
- **고운바탕 + EB Garamond / Crimson Pro(1·2안)** — 고서 맛은 더 났지만, 연구자가 작은 글씨의 가독성을 앞세워 3안을 골랐다
- **지도 배경을 세피아로** — 자료의 색이 바뀐다
