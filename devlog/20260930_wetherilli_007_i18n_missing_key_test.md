# wetherilli 007 — 번역이 빠진 문구를 잡는 시험

2026-09-30 · `feature/ui-polish`

## 1. 왜

GSM 조사에서 가져온 것(연구자가 고름). GSM 은 `test_i18n` 이 번역표에 빠진 문장을 잡는다. 우리는 027 에서 문구를
`i18n.js` 한 곳에 모았지만, 열쇠가 빠지면 `tr()` 이 **열쇠 이름을 그대로 화면에 낸다**(`"copy.done"`). 영어판에서만
빠진 `DOM_EN` 은 한국어 원문이 영어판에 그대로 남는다. 이번 작업(001~006)에서만 문구 열쇠를 스무 개 가까이 더했다.

## 2. 무엇을 했나

`web/viewer/tests.py` 에 `I18nTest` 셋 — CI 의 `manage.py test viewer` 가 돌린다.

- `T` 의 칸이 모두 `["한국어", "영어"]` 두 문자열인가
- map.js 의 `tr("열쇠")` 와 `tr(조건 ? "a" : "b")` 의 열쇠가 모두 `T` 에 있는가
- 템플릿의 `data-i18n`·`data-i18n-html`·`data-i18n-attr` 열쇠가 모두 `DOM_EN` 에 있는가

뷰어 이미지에는 JS 실행기가 없어(node 를 들이지 않는다) 정규식으로 읽는다. 열쇠를 지워 시험이 실패하는 것을 보았다.

## 3. 시험이 못 잡는 것 — 규칙으로 둔다

열쇠를 변수에 담아 넘기면(`var k = "copy.done"; … tr(k)`) 글자로는 찾을 수 없다. 이번에 그렇게 쓴 곳(좌표 복사, 006)을
`tr("copy.done")` 으로 고쳤다. **`tr` 에는 열쇠를 글자 그대로, 또는 `조건 ? "a" : "b"` 로 넘긴다.**

## 4. 버린 것

- **쓰이지 않는 열쇠 찾기** — `DOM_EN` 의 `title` 처럼 map.js·템플릿 밖에서 쓰는 것이 있어 오탐이 난다
