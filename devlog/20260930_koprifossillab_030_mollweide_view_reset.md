# 030 — 몰바이데에서 지구가 옆으로 밀려 남던 것, 돌리는 동안의 세로 이동

2026-09-30 · `feature/mollweide-rotate-only` · koprifossillab

## 1. 무엇이 문제였나

연구자: `#age=250&proj=moll&lon=-65.2` 를 주소창에 붙여 넣었더니 지구가 화면 가운데에서 왼쪽으로 밀려 있다 — 회전과
옮기기(pan)를 혼동한 것 같다. 그리고 돌리는 도중에는 세로로 움직여도 옮겨지지 않게.

새로 여는 것은 재현되지 않았다(창 크기 여섯·배율 1.25, 늘 가운데). 원인은 둘이었다.

1. **같은 탭에서 # 만 바뀐 주소로 가면 다시 불러오지 않는다**(같은 문서 안의 이동). 뷰어는 `hashchange` 를 듣지 않아,
   그 탭에서 앞서 옮겨 둔 지도(0.15.2 의 지구 밖 끌기)가 그대로 남고 **주소의 `lon` 도 적용되지 않았다** — 재현에서
   주소는 −65.2° 인데 실제 가운데 경도는 45.7° 였다
2. **휠 확대·축소** — Leaflet 은 커서를 가운데로 확대·축소한다. 몰바이데는 이동 범위를 위경도 사각형으로 가둘 수 없어
   (024) 지구 전체가 들어오는 크기까지 줄여도 지구가 옆에 남는다

주소는 가운데 경선(회전)만 담고 옮기기·확대는 담지 않는다 — 그것은 그대로 둔다(나누는 링크는 "어느 시점의 어느 쪽
지구" 면 된다).

## 2. 어떻게

- **`hashchange` 에서 주소대로 다시 맞춘다**(`applyHash`) — 시점·투영·가운데 경선, 그리고 지구 전체를 가운데에.
  처음 열 때도 같은 함수를 쓴다. 우리가 쓰는 `history.replaceState`(writeHash)는 `hashchange` 를 부르지 않아
  되먹임이 없다. 언어는 다시 불러와야 바뀌므로, 주소에 `lang=` 이 **적혀 있고** 지금과 다를 때만 다시 불러온다 —
  `lang` 이 없는 링크는 기억한 언어 그대로
- **몰바이데에서 지구 전체가 들어오는 크기(`worldZoom`) 이하로 줄이면 가운데로 돌려놓는다**(`zoomend`). 확대한
  상태의 옮기기, 그 크기에서 지구 밖을 끌어 옮기기(029)는 그대로 둔다
- **돌리는 동안 세로 움직임은 버린다** — 025 는 지구 안을 끌 때 세로로 옮겼다. 손이 떨리면 지구가 오르내렸다.
  세로로 옮기려면 지구 밖을 끈다(029)

## 3. 확인

헤드리스 크롬: 밖을 끌어 옮긴 뒤 # 만 다른 주소로 가기 → 다시 불러오지 않고 가운데·주소의 경도로, 커서를 옆에 두고
휠 확대 뒤 축소 → 가운데, 지구 안 대각선 끌기 → 돌기만, 새로 열기, 주소로 영어·한국어·정거원통 바꾸기,
`lang` 없는 주소는 다시 불러오지 않음.

## 4. 버린 것

- **주소에 옮기기·확대까지 담기**(`&z=…&c=…`) — 링크가 길어지고, 받는 사람의 창 크기가 달라 같은 화면이 안 된다
- **몰바이데에서 늘 가운데로 붙들기** — 029 의 지구 밖 끌기(옮기기)를 막는다
