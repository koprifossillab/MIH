# wetherilli 014 — 그림 단추를 도구 묶음으로, 거리 재기·링크·전체 보기

2026-09-30 · `feature/panel-find-cleanup`

## 1. 왜

연구자: "그림 다운로드 버튼이 혼자 놀아서 아쉬운데, gsm 참고해서 도구탭으로 만들어줘." GSM 은 지도 오른쪽 위에 세로
손잡이 묶음(점·거리·넓이·범위·그림·3D | 지우기)을 두고, 아이콘 밑에 이름을 적고, 잰 결과는 묶음 왼쪽 칸에 적는다.

## 2. 무엇을 했나

- 오른쪽 위에 `도구` 묶음: **전체 · 거리 · 링크 · 그림 | 지우기**. 모양은 GSM 그대로(50 px, 아이콘 밑 이름, 켜진 도구는
  `--accent` 바탕). 좁은 창에서는 이름을 빼고 44 px
- **거리**: 눌러 가며 잇고 두 번 누르거나 Esc 로 끝낸다. 커서까지 고무줄 선. 선은 대권을 1° 남짓으로 쪼개 긋고 이음매에서
  끊는다(`splitLine`, 028 — 몰바이데 가운데 경선을 돌려도 맞다). 재는 동안 산지 팝업은 열지 않는다
- 잰 값은 **그 시점의 고좌표로 잰 대권 거리**다. 시점을 옮기면 땅이 움직여 점들이 뜻을 잃으므로 지운다
- **링크**: 지금 주소(`#age=…&proj=…&lon=…&lang=…`, 030)를 복사한다. http 에서는 006 의 execCommand 길
- **전체**: 지구 전체로 돌아간다 — 확대 단추(001 에서 뺐다)가 없어 휠로 멀리 간 뒤 돌아오는 길이 없었다
- 잰 선은 그림 내려받기에도 찍힌다. 떼어 낸 SVG 는 CSS 토큰을 못 읽어 Leaflet 기본 파란 실선으로 나왔다 — 계산된
  stroke·dash 를 속성으로 적어 넣는다

## 3. 버린 것

- GSM 의 점·넓이·범위 — 고지리 지도에서 쓸 일이 적다. 넓이는 판이 움직이는 지도에서 뜻이 약하다
- 거리 선을 시점을 따라 옮기기 — 두 점을 지금 좌표로 되돌려 다시 돌리려면 판 회전 모델이 뷰어에 있어야 한다(파이프라인 몫)
