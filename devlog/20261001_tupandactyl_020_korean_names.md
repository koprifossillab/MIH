# tupandactyl 020 — Casual 모드의 한글: 학명 음차·연대·암상

2026-10-01 · `feature/ko-names`

## 1. 무엇을 바랐나

연구자: "캐주얼 모드에서는 연대와 암상을 한국어로 써 주고, 내가 주는 기준을 적용해서 속과 종 단위 명칭을 한국어로 음차해 주길 바래.
이건 scientific 모드에서는 적용되지 않아." 기준은 고전 라틴어 글자 → 한글 표(그림)와 세부 규칙(반모음 j·y·w, 파열음 받침, th·ts,
h, n, 겹자음, 어두 M·N, sh, 장모음, Q, Ds 등)과 예시. "검색 시에는 띄어쓰기로 종 단위까지", 관용 표기 목록은 찾기에서만 받는다.
작업 중에 "종명 끝에 i 붙는거 [-아이]로 읽지 마. [-ㅣ]로 끝나는거야", 이어서 "모든 장모음은 다 장음을 따로 표기하지 않아. aa, uu, ii,
ee, oo, ww 다" — 겹친 모음과 ww 를 자리와 상관없이 한 번으로 줄인다(kingii 킹기, Shiikia 시키아).

## 2. 음차 — 뷰어의 translit.js

학명은 PBDB 에서 그때그때 오므로(팝업·찾기·툴팁) 파이프라인이 미리 옮길 수 없다. 규칙을 **뷰어의 한 파일(translit.js)** 에 두고
연구자의 예시 53 개를 시험(web/viewer/jstest, CI 에서 node 로)에 걸었다. 두 단계다.

1. **글자 → 소리 단위** — 장모음·겹자음을 먼저 줄이고(mm·nn 은 남김), 두 글자 자음(ch kh ph th rh gh sh zh ts tz, 어두 ds)과
   반모음(j·y·w 를 뒤 모음과 묶어), h(어두·모음 사이만), n 의 [ŋ](c g k q 앞), ng 뒤 g(모음·l r m n 앞에서만)를 가른다
2. **소리 → 음절** — 뒤가 모음이면 첫소리. 아니면 m n l 은 앞 음절 받침, 무성 파열음은 앞 음절이 열려 있고 뒤가 l r m n 이 아니면
   받침, 나머지는 '으'를 붙인 음절. 모음 사이의 l 은 ㄹㄹ. w 는 k g h q 뒤에서만 합치고 그 밖엔 앞 자음에 '으'. q 는 [kʷ]

예시 사이에 어긋나는 것이 둘 있어 하나를 골랐다.
- **sh** — 제3항(나야시·슈링가사우루스)과 "22 년 이후"(나야쉬·쉬링가사우루스)가 다르다. 제3항을 따랐다 — 연구자 확인 필요
- **AE·OE** — 표대로 아이·오이(아르카이옵테릭스, 코일로피시스). 관용 표기 목록의 "아르카에옵테릭스·코엘로피시스" 는 찾기에서만 받는다

## 3. 어디에 한글을 쓰나

- **속·종(아속·아종)만** — 계급을 아는 자리에서만 옮긴다(팝업 산출 목록의 accepted_rank, 찾기 후보의 계급, 찾은 이름은 taxa/single 의
  계급을 안 뒤). 과·목 이상은 학명 그대로. 계급을 모르면 옮기지 않는다 — "Mesosauridae" 를 속처럼 읽지 않게
- 한글 이름에 커서를 대면 학명. 찾기 후보에는 한글과 학명을 나란히
- **연대** — PBDB 시대 이름이 층서표 단위의 영어 이름과 같으면 그 한글 이름(Artinskian → 아르틴스크절), "Early/Middle/Late + 절"
  은 "절 전기/중기/후기". 지역 시대 이름(Wonokan 등)은 그대로
- **암상** — `pipeline/lithology.py` 의 사전(PBDB 전체 산지에 나온 주 암상 54·형용 12 전부)을 index.json 으로. 던햄 분류(packstone 등)는
  우리말이 없어 음차

## 4. 찾기

- **띄어쓰기 종** — PBDB 가 "Tyrannosaurus rex" 를 그대로 받는다(taxa/auto·taxa/single 확인). 막던 것은 없었다
- **한글 입력** — PBDB 는 학명만 알므로, 한글은 연구자가 준 **관용 표기 목록**에서만 학명으로 바꿔 찾는다(후보에 "관용 표기 ‘시조새’").
  목록의 철자 몇은 PBDB 이름으로 고쳐 넣었다 — Australopitecus → Australopithecus, Mammuth → Mammut, Confuciuornis → Confuciusornis,
  Dreadnaughtus → Dreadnoughtus. 규칙으로 만든 한글 이름(티란노사우루스)을 거꾸로 학명으로 찾는 것은 하지 않았다 — 한글 → 라틴은
  하나로 정해지지 않는다
