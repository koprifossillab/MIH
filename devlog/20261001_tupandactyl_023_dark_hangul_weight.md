# tupandactyl 023 — 다크 모드 Casual 의 한글을 본명조 600 으로

2026-10-01 · `feature/popup-resize-guide`

## 1. 무엇을 바랐나

연구자: "캐주얼모드의 현재 한글 필체가 다크모드에서 보기에는 좀 불편하네". 후보(마루 부리·고운바탕·함렛·이롭게 바탕, 또는 본명조를 굵게)를
알리자 "본명조 두께를 올리면 어떻게 보여?" — 다크 모드에서 A 지금(400)·B 한글만 600·C 전부 600 을 찍어 보였고 "한글만 600 으로".

## 2. 어떻게

- **한글만 굵게** — `font-weight` 를 올리면 라틴(Spectral)과 숫자까지 굵어져 화면이 빽빽해진다(C). 그래서 굵기는 그대로 두고 **한글 글꼴을
  600 파일로 바꿔 끼운 별칭 가족 'Noto Serif KR Dark'** 를 둔다 — 400·600 자리 모두 600 파일. 다크 모드 Casual 의 `--font` 만 그 가족을 쓴다
- **새 파일을 받지 않는다** — 이미 담은 600 묶음을 가리킨다. 별칭 CSS(`fonts-dark.css`)는 `python design/fetch_fonts.py --dark` 가 fonts.css 에서
  만든다(받지 않는다). fonts.css 처럼 손으로 고치지 않는다
- 밝은 모드는 400 이 잘 읽혀 그대로. Scientific 은 Pretendard 라 상관없다
- 버린 것: 다른 글씨체로 바꾸기 — 빈티지 결이 바뀌고 글꼴을 새로 담아야 한다. 굵기만으로 충분했다
