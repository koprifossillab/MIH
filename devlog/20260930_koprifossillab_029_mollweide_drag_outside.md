# 029 — 몰바이데에서 지구 밖을 끌면 지도를 옮긴다

2026-09-30 · `feature/mollweide-drag` · koprifossillab

## 1. 왜

연구자: 몰바이데에서 드래그할 때 커서가 지구 안에 있을 때만 회전시키고, 다른 위치에서는 그대로 드래그.
025 는 몰바이데에서 어디를 끌든 가로는 돌리기였다. 확대해 지구 가장자리를 볼 때나 지구를 화면 한쪽으로 치우고
싶을 때 옮길 방법이 없었다.

## 2. 어떻게

- **누른 자리가 타원 안이면 돌리기**(가로는 가운데 경선, 세로는 옮기기 — 025 그대로), **밖이면 옮기기**(가로·세로 모두
  `panBy`). 판정은 커서 자리의 기온·좌표를 가리던 `onGlobe`(024)를 그대로 쓴다 — 화면 자리를 투영 평면으로 바꿔 타원 식
- **누른 순간에 정하고 끄는 동안 바꾸지 않는다** — 밖에서 안으로 끌어 들어올 때 옮기다 갑자기 돌면 손 밑의 지도가 튄다
- 옮기기도 Leaflet 의 끌기를 켜지 않고 같은 pointer 처리(`spin`)로 한다 — 몰바이데에서는 Leaflet 끌기가 꺼져 있고(025),
  켜고 끄는 것보다 한 곳에서 가르는 편이 간단하다. 관성(끌고 놓으면 미끄러지기)은 없다

## 3. 확인

헤드리스 크롬, 250 Ma 몰바이데: 타원 안 끌기 → 가운데 경선이 돌고 세로로 옮겨짐, 타원 밖 끌기 → 가운데 경선 그대로
지도가 끈 만큼 옮겨짐, 밖에서 안으로 끌기 → 끝까지 옮기기, 끈 뒤 팝업 안 열림.

## 4. 버린 것

- **끄는 도중 경계를 넘으면 방식 바꾸기** — 손 밑이 튄다
- **밖에서는 Leaflet 끌기(관성 포함)** — 누를 때마다 Leaflet 끌기를 켜고 끄면 이미 시작된 끌기와 엉킨다
