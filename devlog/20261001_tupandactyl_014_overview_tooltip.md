# tupandactyl 014 — 종합 보기의 툴팁을 시점 찾기와 같게

2026-10-01 · `feature/overview-tooltip`

## 1. 무엇을 바랐나

연구자: "0 Ma 분류군 검색 시 커서를 대면 뜨는 정보, 어차피 포인트당 산지는 거진 1곳이잖아? 시점 옮겼을 때처럼 뜨게 만들어 줘. 거기에
시대정보만 더하고." 012 의 툴팁은 칸 단위("산지 n곳 · 나이 범위")였다 — 0.25° 칸이라 대부분 산지 한 곳인데 이름도 분류군도 없었다.

## 2. 어떻게

- **같은 함수를 쓴다** — 시점 찾기의 `taxonTip`(산지 이름 굵게 + 산출 목록, 같은 이름은 묶어 건수, 5종부터 "산출 n종 — 누르면 목록")에
  시대 한 줄(`early_interval – late_interval · max–min Ma`)만 끼운다. 두 화면의 툴팁이 따로 놀지 않게
- **산출은 커서를 댈 때 묻는다** — 종합 보기는 `colls/list`(산지)라 산출 이름이 없다. 처음부터 `occs/list` 로 받으면 삼엽충은 수만 건이라
  무겁다. 커서를 댄 산지 하나만 `occs/list?coll_id&base_name` 으로 묻고 기억한다(분류군·산지 짝으로). 오는 동안은 "읽는 중…" 을 띄우고,
  오면 열려 있는 툴팁을 바꾼다
- 나라만 찾은 종합 보기는 분류군이 없으니 산지 이름·시대·산출 건수
- 칸에 산지가 여럿이면 이름과 시대를 5 곳까지, "누르면 산지 목록"

## 3. PBDB 산지 링크의 403

연구자: "pbdb 링크가 존재는 하지만 실제로 들어갔을 때 403 forbidden". 팝업 링크 `classic/basicCollectionSearch?collection_no=` 를 PBDB 의
nginx 가 403 으로 막는다(브라우저 UA 로 물어도 같다). 같은 산지를 `classic/displayCollectionDetails?collection_no=` 로 물으면 200 과 산지
상세 쪽(지층·산출 목록)이 온다 — 그쪽으로 바꿨다. API(`data1.2`)는 그대로 열린다. 링크를 거는 곳은 `PBDB_COLL_PAGE` 하나다.
