# 007 — 해양기원 점을 에메랄드·민트(열대 바다) 색으로 바꾼다

2026-09-29 · `work/20260929-koprifossillab`

## 1. 무엇이 문제였나

003 에서 해양기원을 하늘색→남색으로 칠했다. 배경(PaleoDEM)의 바다도 하늘색(대륙붕)→남색(심해)이라
**해양 채집지가 대개 같은 색 바다 위에 앉았다.** 흰 테두리로 버텼지만 004 에서 점을 반투명(60%)으로
내리자 더 묻혔다. 연구자가 "열대 바다 같은 에메랄드~민트빛" 을 청했다.

## 2. 색

청록(색상 약 160°)은 배경의 바다(약 200~220°)와 지형의 녹갈색(약 40~100°) 사이에 비어 있는 자리다.
육상기원의 주황~빨강(약 10~30°)과는 보색에 가까워 둘이 섞여 있어도 갈린다.

순서의 뜻은 그대로 둔다 — 해안에서 심해로 갈수록 **민트 → 에메랄드 → 짙은 청록**:

| 환경군 | 색 |
|---|---|
| 해안·연안 [미상] | `#a6f7d6` |
| 석호 | `#84f2cb` |
| 쇄설성 전빈·외빈 | `#62ebbd` |
| 삼각주 전면부·전삼각주 | `#44e0ae` |
| 탄산염 조간대·천해성 조하대 | `#2ad3a0` |
| 생물초 | `#14c292` |
| 쇄설성 외해 | `#0fad85` |
| 탄산염 심조하대·외해 | `#0c9577` |
| 경사면·분지·심해 | `#0a7a66` |
| 해양 [미상] | `#1fd1a1` (갈래의 가운데) |

가장 옅은 민트는 밝은 대륙붕 위에서 조금 약하다. 더 짙게 하면 순서의 앞끝이 뭉개져 두었다 —
흰 테두리가 경계를 잡는다. 더 필요하면 점 불투명도를 올린다.

색은 `pipeline/environments.py` 한 곳에 있고 index.json 으로 가므로 목록만 다시 만들었다(`build --no-relief`).
화석 파일은 그대로다.
