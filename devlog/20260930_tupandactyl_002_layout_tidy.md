# tupandactyl 002 — 시점 막대를 맨 위로, 찾기 칸을 떠 있는 카드로, 잔정보는 설정 창으로

2026-09-30 · `feature/layout-tidy`

## 1. 무엇을 바랐나

연구자가 화면을 정리하기를 바랐다.

- 지도 밑 줄의 "분류군 또는 국가" 찾기를 **지도 위에 떠 있는 창**으로, 직접 끌어 옮기게
- 시점은 **맨 윗줄에 꽉 차게**, 각 시기 이름을 **영어로**, 긴 이름은 약자로
- 화석 산지의 퇴적 환경은 처음에 **해양·육상·미상기원만** 보이게 접어 둔다
- 연대 범위를 어떻게 정했는지, 수의 뜻, 층서표 이름 기준 같은 **잔정보는 설정 · 자료 안으로**
- "그림" 은 헷갈리니 **"다운로드"** 로
- 명칭 고치기는 끝났으니 **끈다**

## 2. 시점 막대

막대·◀▶·기와 세의 띠·산출 막대(010)·"차례로 보기" 를 머리말 밑 한 줄로 옮겼다. 층서표 칩(대·기·세·절)은 네 줄이라 창
폭 한 줄에 넣으면 지도가 좁아져서 왼쪽 패널에 남겼다. 절 제목은 "층서표로 고르기" 다.

**띠의 이름은 화면 언어와 상관없이 영어다** — 연구자가 바란 것이고, 층서 이름을 가장 넓게 알아보는 꼴이다.
index.json 의 `en` 을 쓴다. 한국어 이름은 커서를 댔을 때의 title 에 함께 적는다.

**약자는 규칙으로 만든다.** ICS 의 기호(Cm, O, S …)를 쓰면 좋지만 그것은 층서 자료라 map.js 에 적으면 CLAUDE.md 의
"층서 이름을 map.js 에 다시 적지 않는다" 를 어긴다. 그렇다고 index.json 에 약자 칸을 더하면 파이프라인을 다시
돌려야 한다(운영 가공물이 바뀐다). 그래서 이름에서 만든다: 긴 것부터 `Late Cretaceous` → `L. Cretaceous` →
`L. Cret.` → `LCr` 을 두고, 띠의 실제 폭(캔버스로 글자 폭을 잰다)에 드는 가장 긴 것을 적는다. 아무것도 안 들면
비운다(홀로세·제4기처럼 몇 px 인 띠). 창 크기가 바뀌면 다시 맞춘다. ICS 기호가 꼭 필요해지면 timescale.py 에 칸을
더하는 것이 맞는 자리다.

## 3. 찾기 카드

지도 칸(`.mapcol`) 안에 절대 위치로 띄운다 — `#map` 안에 넣으면 Leaflet 이 누르기·휠을 가로채므로 형제로 둔다.
카드의 빈 자리나 ⠿ 를 끌면 옮기고, 칸·단추·딱지·후보 목록을 누른 것은 끌기로 보지 않는다. 자리는 지도 칸에 대한
**비율**로 기억한다 — 창 크기가 바뀌어도 비슷한 자리에 있고, 지도 칸 밖으로 나가지 않게 가둔다. 후보 목록은 카드가
지도의 위쪽 절반이면 아래로, 아래쪽이면 위로 연다(전의 막대는 늘 위로 열었다).

## 5. 잔정보

설정 · 자료 창에 "읽는 법" 절을 만들어 옮겼다: 산지가 시점에 오르는 규칙, 수의 뜻, 연대 범위 막대, 모호한 연대,
층서표 이름·경계 기준. 배경 격자 안내(PaleoDEM 0.1° 격자, 폭)도 자료 절로 옮겼다. **패널에 남긴 안내는 그 시점의
상태를 말하는 것뿐이다** — 해안선이 가장 가까운 나이의 것이라는 것, 기온 자료가 없다는 것, 연대 범위로 가린 수 같은
것. 이것들은 지금 보는 지도를 읽는 데 필요하다.

"수: 산지 수(지금 지도)" 줄은 지우고 같은 말을 환경 나무의 title 로 둔다 — 분류군을 찾는 동안에는 산출 건수로 바뀐다.

## 6. 명칭 고치기를 끈다

화면의 ✎ 단추·편집 막대·저장 코드를 지웠다. 운영 `state/` 에 `labels.json` 이 없다 — 고친 이름은 0.4.0 에 이미
environments.py 로 옮겼다(003). 서버의 `/labels`(`viewer/labels.py`)는 그대로 두었다: GET 은 덮어쓰기가 있으면 뷰어가
읽어 입히고, POST 는 운영 `.env` 의 `WEGENER_EDITOR_KEY` 로만 열린다. 완전히 닫으려면 그 열쇠를 지운다 —
서버 코드를 지우는 것은 `/labels` 시험 5 개까지 걸려 이번 일의 범위를 넘는다고 보았다.
