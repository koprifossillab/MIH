# wetherilli 003 — 투영 단추를 머리말로, 언어·자료는 설정 창으로

2026-09-30 · `feature/ui-polish`

## 1. 왜

연구자: "투영법 변환 버튼은 지금의 한국어/영어 변경 버튼처럼 만들어줘." 그리고 GSM 의 ⚙ 설정 창을 가져오되
그 자리에 **언어 바꾸기와 맨 아래 참고문헌(자료)** 을 넣는다. GSM 조사(설정 시트 — 모양·판 이력·상태)에서 우리에게
맞는 것만 골랐다.

## 2. 무엇을 했나

- **투영**: 패널 맨 위의 라디오 줄(024)을 지우고 머리말 오른쪽에 `정거원통 | 몰바이데` 붙은 단추. 언어 단추(027)와
  같은 꼴이라 CSS 를 `.seg` 하나로 합쳤다(`aria-pressed`). 옛 가공물(몰바이데 배경 없음)이면 전처럼 숨는다
- **⚙ 설정 · 자료**: 머리말 맨 오른쪽 단추가 `<dialog>` 를 `showModal()` 로 연다. Esc·✕·바깥 누르기로 닫힌다.
  모달이라 뒤의 지도·패널은 눌리지 않는다
  - **언어** — 머리말에 있던 `한국어 | English`
  - **자료** — 패널 맨 아래에 있던 출처 목록·판 모델 설명·판 번호와 가공 날짜
- 패널에서 "투영" 줄과 "자료" 절이 빠져 패널은 지도를 다루는 것만 남았다

## 3. 왜 이렇게 나눴나

- 투영은 지도를 보는 동안 자주 바꾼다 — 한 번 누르는 자리(머리말)에 둔다. 언어는 한 번 정하면 기억되고(027),
  출처는 가끔 읽는다 — 창 하나로 걷어낸다
- `<dialog>` 는 Esc·포커스 가두기·`role=dialog` 를 브라우저가 해 준다. GSM 은 직접 짰지만 우리는 그럴 까닭이 없다

## 4. 버린 것

- **GSM 의 테마·글꼴·글자 크기 고르기, 판 이력** — 연구자가 설정 창에 넣을 것으로 언어·참고문헌만 골랐다.
  테마는 지금처럼 운영체제의 밝게/어둡게를 따른다
- **언어를 머리말에 그대로 두고 설정 창에도** — 한 가지 일을 두 곳에서 하게 된다
