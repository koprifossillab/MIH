# tupandactyl 013 — 대기 화면을 빠르게, "느리게 보기"

2026-10-01 · `feature/splash-speed`

## 1. 빠르기

연구자: "인트로 화면은 1.7배에서 2배 정도 재생속도를 빠르게 하고, 구석에 느리게 보기 옵션을". 시계의 배수(`SPEED`)를 1.3 → 2.4 로 —
그 사이의 가운데(1.85 배)다. 시간표(헤엄·펜·뼈)는 그대로 두고 시계만 빠르게 한다는 앞의 결정(tupandactyl 005)을 따른다. 끝 모습까지
7.4 초가 4.2 초로 줄었다(시험 서버에서 잰 값). 메달이 떠오르는 것과 부제는 CSS 전환이라 시계를 따르지 않아 따로 줄였다 — 그대로 두면
빨라진 헤엄이 메달을 두를 때 메달이 아직 흐리다.

## 2. "느리게 보기"

- **오른쪽 아래** — 위쪽은 머리글의 겹줄과 "Tafel I." 에 붙고, 아래쪽 가운데는 도판 설명이다. 좁은 화면에서는 도판 설명을 단추 위로 올린다
- **0.27 까지의 빠르기(1.3)** 로 돌린다 — 연구자가 다듬으며 본 빠르기라 "느리게" 의 기준으로 맞다
- **기억한다**(`localStorage` `wegener.splashSlow`) — 한 번 고르면 다음에도. 대기 화면은 지도보다 먼저 떠서 설정 창에 둘 수 없다
- **도는 중에 눌러도 튀지 않는다** — 지금까지 흐른 시계를 새 배수로 나눠 시작 시각을 다시 맞춘다
- 단추를 누르는 것은 건너뛰기가 아니다(누름·Space·Enter 모두). 화면 움직임 줄이기를 켠 사람에게는 끝 모습만 보이므로 단추도 없다
