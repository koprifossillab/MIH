# wetherilli 004 — 분류군·국가 찾기를 지도 아래 막대로

2026-09-30 · `feature/ui-polish`

## 1. 왜

연구자: "분류군 찾기와 국가 찾기는 GSM 처럼 지도 화면 하단에 묶어줘." GSM 은 지도 아래 좌표 막대 하나에서
좌표·주소를 찾는다. 우리 찾기 칸 둘은 패널의 셋째·넷째 절에 있어, 시점을 옮기다 찾으려면 패널을 한참 내려가야 했다
(좁은 창에서는 더).

## 2. 무엇을 했나

- 지도 칸을 `.mapcol`(지도 + 막대)로 감싸고, 지도 바로 아래에 **찾기 막대** — `분류군 [칸] ✕ [찾기]  국가 [칸] ✕`
- 두 칸의 **후보 목록은 위로 연다** — 막대가 화면 맨 아래라 아래로 열면 잘린다
- "분류군 지우기"·"국가 지우기" 글자 단추는 칸 옆 ✕ 로. 브라우저의 검색 칸 ✕ 는 숨겼다 — 글자만 지우고 거르기는
  남아, ✕ 가 둘이면 어느 것이 무엇을 하는지 헷갈린다
- **결과는 패널에 그대로** — 분류군 절(찾은 수·산출 시대·같은 시대 다른 산지·차례로 보기), 국가 절(안내·"이 나라로
  다시 가기"). 요소의 id 를 바꾸지 않아 map.js 는 손대지 않았다
- 좁은 창에서는 막대가 지도와 패널 사이에 온다. 폭이 모자라면 두 칸이 두 줄로 꺾인다

## 3. 버린 것

- **GSM 처럼 지도 위에 반투명하게 띄우기** — Leaflet 의 아래 모서리 컨트롤(축척·출처·커서 기온)을 막대 높이만큼
  올려야 하고, 몰바이데에서 극 부분이 가린다. 지도 칸을 줄이고 그 아래에 붙였다
- **결과(산출 시대 분포 등)까지 막대로** — 막대가 커져 지도를 먹는다. 막대는 묻는 곳, 패널은 답하는 곳으로 나눴다
