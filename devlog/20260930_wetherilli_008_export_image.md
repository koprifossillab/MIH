# wetherilli 008 — 지도를 그림으로 내려받기

2026-09-30 · `feature/ui-polish`

## 1. 왜

GSM 조사에서 가져온 것(연구자가 고름). 발표·논문 초안에 지도를 넣으려면 화면을 잘라 붙여야 했고, 잘라 낸 그림에는
몇 Ma 인지·무엇을 걸렀는지·출처가 남지 않았다.

## 2. 무엇을 했나

- 지도 오른쪽 위 **⤓ 그림** 단추 — 지금 보이는 지도를 PNG 한 장으로 받는다(`wegenersdream_250Ma_moll.png`)
- **옮겨 그리기**: 지도는 창(pane)마다 따로 그려져 있다 — 배경(캔버스, 380), 기온(캔버스 또는 그림, 390),
  해안선·국경·경위선(SVG, 400), 산지(캔버스, 450). 겹 순서대로, 화면에 놓인 자리(`getBoundingClientRect`)와
  불투명도 그대로 한 캔버스에 옮긴다. SVG 는 직렬화해 그림으로 읽는다. 지도 칸 밖으로 나간 것(캔버스 여백)은 자른다
- **축척 막대**(001)를 같은 자리에 다시 그린다
- **밑 띠**: `Wegener's Dream  250 Ma 중생대 › 트라이아스기 › 전기 › 인더스절 · Permo-Triassic Boundary · 전 지구 평균 32.9 ℃`,
  둘째 줄에 투영·분류군·국가·점 색(시대일 때), 셋째 줄에 출처 표기·주소(시점·투영·가운데 경선이 든 것)·받은 날짜.
  **띠는 밝은 바탕에 고정** — 어두운 모드에서 받아도 슬라이드·인쇄에 그대로 쓰게
- 화면 배율(`devicePixelRatio`)대로 굽되 2 배까지

## 3. 걸린 것

- SVG 를 그대로 직렬화하면 Leaflet 이 자리를 잡으려 붙인 `transform: translate3d(…)` 가 그림 안에서 다시 먹어 선이
  밀렸다 — 복사본에서 `style` 을 지운다
- 몰바이데에서 기온 층이 처음 켤 때 그려지지 않았다(그림에도 빠졌다) — 따로 고쳤다(wetherilli 009)

## 4. 버린 것

- **leaflet-image·html2canvas 같은 라이브러리** — 몰바이데 배경은 우리가 캔버스에 행마다 옮겨 그리는 것(025)이라
  라이브러리가 모른다. 창 넷을 옮겨 그리는 것은 60 줄이다
- **온도계(002)·범례를 그림 안에** — 평균 기온은 띠에 숫자로 적는다. 범례는 패널에 흩어져 있어(환경 나무·시대 색)
  옮기려면 따로 그려야 한다. 필요해지면 그때 더한다
