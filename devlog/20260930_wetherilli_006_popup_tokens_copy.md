# wetherilli 006 — 팝업 색을 토큰으로, 고좌표는 눌러서 복사

2026-09-30 · `feature/ui-polish`

## 1. 왜

GSM 조사에서 가져온 둘(연구자가 고름).

- **어두운 모드의 팝업**: 패널·머리말은 `prefers-color-scheme` 로 어두워지는데, Leaflet 팝업·툴팁은 흰 바탕 그대로였고
  그 안의 `dt` 는 `#666`, 산출 목록의 분류는 `#777`, "모호한 연대" 는 `#9a5b00` 로 적혀 있었다. 흰 바탕 위에 흐린 회색이고,
  어두운 모드에서는 둘레(어두운 지도·패널)와 팝업만 따로 놀았다. GSM 의 원칙 — **색은 전부 토큰으로만**
- **좌표 복사**: 산지의 고좌표를 다른 곳(논문 표, GPlates 등)에 옮겨 적으려면 손으로 옮겨 써야 했다

## 2. 무엇을 했나

- 팝업(`.leaflet-popup-content-wrapper`·꼬리), 산출 툴팁(`.occ-tip` 과 네 방향 꼬리), 출처 표기를 `--panel`·`--ink`·
  `--muted`·`--accent` 로. 주의 글씨에는 `--warn` 토큰을 새로 두었다(밝게 `#9a5b00`, 어둡게 `#e6a64a`)
- map.css 에 남은 고정 회색(`#666`·`#777`)이 없다
- 팝업의 **고좌표를 누르면 `위도, 경도`(숫자만)를 복사**하고 옆에 "복사했다" 가 0.9 초 뜬다. 점선 밑줄과 `cursor: copy`
  로 눌리는 것임을 알린다
- 운영은 http 라 `navigator.clipboard` 가 없다(보안 맥락에서만 열린다). 그때는 숨긴 textarea 에 `execCommand("copy")` —
  GSM 과 같은 길이다. 둘 다 안 되면 "복사하지 못했다"

## 3. 버린 것

- **지금 좌표도 복사** — 산지 파일에는 고좌표만 있다(`FIELDS`). 지금 좌표를 넣으려면 파이프라인을 고쳐 가공물을
  다시 만들어야 한다. PBDB 산지 링크에서 볼 수 있다
- **팝업 전체를 텍스트로 복사** — 쓰는 곳이 분명하지 않다
